第 1 步 · 横着排

容器：ui.row 和 ui.column

容器是用来装其他组件的组件。组件放进哪个容器，就按那个容器的方式排列。

代码作用英文意思
with ui.row():下面缩进的组件横着排成一行row = 行
with ui.column():下面缩进的组件竖着排成一列column = 列
ui.label("竖着排（默认）：")
for c in ["动物", "食物", "物品"]:
    ui.button(c)

ui.label("放进 ui.row()，横着排：")
with ui.row():
    for c in ["动物", "食物", "物品"]:
        ui.button(c)

难点：哪些组件在容器里？

和 for、if 一样，with 下面缩进的代码属于它，取消缩进就出了容器。例子：

with ui.row():
    ui.button("提问")        # 在 row 里
    ui.button("我猜是它")    # 在 row 里
ui.button("新游戏")          # 不缩进：在 row 外面，另起一行

第 2 步 · 样式

.classes() 和 .props()

在组件后面接 .classes("...") 或 .props("...")，可以改变它的样子。

代码作用
.classes("text-3xl font-bold")字号变大（3xl）、加粗
.classes("w-full")宽度占满所在的容器（w = width 宽度）
.classes("max-w-xl mx-auto")最大宽度限制在中等大小，并左右居中
.props("outlined")输入框带边框
.props("color=orange")按钮变成橙色
ui.label("猜猜我是谁")
ui.label("猜猜我是谁").classes("text-3xl font-bold")
ui.input(placeholder="输入问题，例如：它会飞吗？")
ui.input(placeholder="输入问题，例如：它会飞吗？").classes("w-full").props("outlined")
ui.button("我猜是它").props("color=orange")

第 1、3 行没加样式，第 2、4、5 行加了。第 1 课里输入框太窄的问题，用 w-full 解决了

难点：.classes 和 .props 有什么区别？

.classes 设置通用样式（大小、宽度、间距、文字颜色），对任何组件都适用；.props 设置组件自己的选项，比如输入框的 outlined、按钮的 color，换一种组件就不一定有。多个样式写在同一个字符串里，用空格隔开。

ui.card 和 ui.chat_message

第 4 步 · 点击后往聊天区加气泡

运行中往容器里加组件

先建一个空的容器 chat 当聊天区。点击按钮时，在函数里用 with chat: 把新气泡放进去。

代码作用英文意思
chat = ui.column()空的竖排容器，存进变量 chat
with chat:接下来生成的组件放进 chat
chat.clear()删除 chat 里的所有组件clear = 清空

"我说一句""AI 说一句"会用很多次，写成一个函数 say：

def say(mine, text):
    with chat:
        if mine:
            ui.chat_message(text, name="我", sent=True)
        else:
            ui.chat_message(text, name="AI")

def ask():
    q = box.value
    if q == "":
        ui.notify("请先输入问题")
    else:
        questions.append(q)
        say(True, q)
        say(False, f"（AI 还没接上，第 5 课再来回答。你已经问了 {len(questions)} 个问题）")
        box.value = ""

难点：忘了写 with chat:

在点击函数里生成的组件，如果没有说放进哪个容器，就会出现在被点击的按钮所在的容器里。例子：去掉 with chat:，气泡跑到了"提问"按钮旁边：

第 4 步 · 本课完整代码

把所有组件放进布局

最外层用一个居中的 ui.column 包住所有组件，问答区放进卡片：

from nicegui import ui

questions = []

def choose(e):
    category.text = f"当前类别：{e.sender.text}"

def say(mine, text):
    with chat:
        if mine:
            ui.chat_message(text, name="我", sent=True)
        else:
            ui.chat_message(text, name="AI")

def ask():
    q = box.value
    if q == "":
        ui.notify("请先输入问题")
    else:
        questions.append(q)
        say(True, q)
        say(False, f"（AI 还没接上，第 5 课再来回答。你已经问了 {len(questions)} 个问题）")
        box.value = ""

def new_game():
    chat.clear()
    questions.clear()
    say(False, "我又想好了一个东西，问我吧！")

def guess():
    g = box.value
    if g == "":
        ui.notify("请先输入你猜的东西")
    else:
        say(True, f"我猜：{g}")
        box.value = ""

with ui.column().classes("w-full max-w-xl mx-auto"):
    ui.label("猜猜我是谁").classes("text-3xl font-bold")
    ui.label("我心里想好了一个东西，你来猜！")
    with ui.row():
        for c in ["动物", "食物", "物品"]:
            ui.button(c, on_click=choose)
    category = ui.label("当前类别：动物")
    with ui.card().classes("w-full"):
        chat = ui.column().classes("w-full")
        box = ui.input(placeholder="输入问题，例如：它会飞吗？").classes("w-full").props("outlined")
        with ui.row():
            ui.button("提问", on_click=ask)
            ui.button("我猜是它", on_click=guess).props("color=orange")
            ui.button("新游戏", on_click=new_game)

say(False, "我想好了一个东西，问我吧！")

ui.run()
