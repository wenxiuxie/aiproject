# 猜猜我是谁 · AI 游戏课

电脑悄悄选好一个东西，AI 知道答案，但只能回答「是」「不是」「不确定」，玩家有 10 次机会猜出来。8 节课，用 Python（NiceGUI + 硅基流动 API）从空白网页一步步写出这个游戏。

- 在线学习：https://wenxiuxie.github.io/aiproject/guess-who/
- `课程/第N课.html`：每课的课件（一屏一题）
- `课程/代码/`：每课做完时的完整代码

运行代码前：`pip install -U nicegui openai`，并在代码第一行 `API_KEY = "在这里粘贴你的 key"` 填入自己的硅基流动 API Key。**不要把填了 key 的代码上传或发给别人。**
