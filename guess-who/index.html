AI 游戏课 · 8 课

猜猜我是谁

电脑悄悄选好一个东西，AI 知道答案，但只能回答「是」「不是」「不确定」。你有 10 次机会把它猜出来。接下来 8 课，你要用 Python 亲手把这个游戏写出来。

课程

第1课搭起游戏界面
组件、ui.run() 第2课让按钮响应点击
事件、读输入框、改文字 第3课排版与聊天气泡
容器、样式、聊天气泡 第4课字典：游戏的记事本
字典、random，游戏能玩了 第5课第一次调用 AI
API、API Key 第6课让 AI 记住对话
对话记录、system 消息 第7课给 AI 立规矩
提示词、检查 AI 的回答、try 第8课完成「猜猜我是谁」
async / await、称号

开始之前

在电脑上装好 Python 和 VS Code，然后在终端运行一次：

pip install -U nicegui openai

每课都会记住你看到第几页（只保存在这台电脑的这个浏览器里）。
